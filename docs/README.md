## 文档约定

- 根 README 负责产品介绍和快速入口；操作细节集中在开发、运维与发布文档。
- V2 总方案保留设计决策；`steps/` 保留实施依赖、当时的检查数量和验收记录，早期阶段限制不代表最终功能缺失。
- 接口和默认配置以当前 Controller、运行脚本、`application.yml`、`.env.example` 和 lockfile 为依据；修改对应实现时同步更新专题文档。
- 新增文档加入本索引；内部链接使用仓库相对路径。V1 资料明确归档，不作为 V2 操作指南。
- 配置、nonce、备份、截图和验收结果不混入公开资源或发布包；不在文档中记录真实凭据。
