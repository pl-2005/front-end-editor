初稿交叉复核后，补充了取消投放零写入、明确的默认性能验收基线、选框与父层选择、模板复用及双浏览器断言，并修正新增文件撤销的 `fileOrder` scope 和远端贡献保护。三个子 agent 已复核修订稿并返回通过，未留下必须修正文档的问题；这不代表功能验收通过。

## 需求来源与默认决策

2026-10-12 后续明确指令：Bootstrap 作为组件栏依赖，原生 HTML 模板路线保持；以下组件类型默认补充为 Bootstrap HTML/CSS 模板。具体版本与依赖分发为[技术方案](bootstrap-dependency.md)，尚未实施，不改写本页早期评审记录。

用户明确授权的是：当前项目基础上的组件栏拖入网页并同步项目文件代码，以及多个子 agent 需求评审并写入 `docs/V__3/`。以下是评审提出的默认方案，不代表用户已经逐条确认；可继续按基线实施准备，改动时同步需求与验收。

| 决策           | 建议默认                                            | 影响                                     |
| -------------- | --------------------------------------------------- | ---------------------------------------- |
| 文件同步目的地 | 当前虚拟文件 + 现有持久化 + ZIP                     | 本机目录/Git 实时同步单独评审            |
| 组件类型       | 原生 HTML/CSS 模板                                  | 不引入任意 React/Vue 源码转换            |
| 拖拽布局       | 文档流、基础 Flex/Grid 的插入排序与嵌套             | 自由坐标定位后续支持                     |
| 设计目标       | 可选项目 HTML，默认入口；不改变运行入口             | 多页面需要独立状态与资源解析             |
| 样式写入       | 新组件专用 CSS/独立实例 class，旧元素简单内联声明   | 保留共享规则、区分计算值与写入值         |
| 图片           | URL/已有可用地址                                    | 不默认新增二进制上传与公共素材存储       |
| 历史           | 共用本地撤销/重做，继承当前持久化                   | 不新增历史版本/检查点                    |
| 并发结构       | 本地重新校验 + 合并检测 + 可说明的源码恢复          | 强语义互斥是否必要由专项验证决定         |
| 设备/规模      | 桌面 Chrome/Edge + 键盘替代；200 KiB 内默认设计范围 | 触摸后续；设计范围阈值为建议而非已有能力 |

## 已解决的评审问题

| 问题                            | 已写入的要求                                        |

## 实施前技术门禁

| 风险                     | 必须获得的证据                                                 | 未通过时的处理                                             |
| ------------------------ | -------------------------------------------------------------- | ---------------------------------------------------------- |
| 跨 iframe 拖入与资源投影 | 真实浏览器验证滚动/缩放/空容器投放，项目 CSS 相对引用正确      | 调整设计 iframe/桥接，不删除组件拖入目标                   |
| 多文件原子补丁与历史     | 双执行一致、任一预检失败无更改；新增 CSS/link 一次撤销完整恢复 | 调整命令生成、文件 ID 接口及共享历史                       |
| 移动与尚未收到的远端更新 | 双会话延迟场景的内容保留、冲突提示和恢复路径                   | 补足恢复或评审网关语义条件/结构互斥；不能只以文本收敛放行  |
| 静态设计安全             | script/事件/URL/SVG/嵌入/导航和伪造通信均有拒绝证据            | 改进受限投影、CSP/隔离和协议；不接触父页凭据               |
| HTML 容错及映射保真      | 隐式节点、实体/emoji/CRLF、混合文本、注释归属和无关区间不变    | 限制有歧义范围并解释，保留代码编辑；不能误写               |
| 设计文件性能             | 指定设备、节点数和 200 KiB 边界下的响应/清理记录               | 优化 worker/投影，必要时经范围决策调整阈值，不冒称已有性能 |

这些门禁是实施准备工作，不是本次需求评审未完成。没有外部发布、部署或破坏性操作需要本轮审批。
