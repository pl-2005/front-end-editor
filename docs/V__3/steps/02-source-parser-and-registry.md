# 步骤 02：源码解析、节点注册表与定位

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P1 基础。前置：[01](01-baseline-and-p0.md) 全部 P0 放行和接口/预算冻结。

## 目标与接入

将 P0 映射原型产品化，为 03 的局部补丁及 05 的受控投影提供可信节点身份。HTML/Y.Text 是权威，解析树不是共享模型。新增建议职责 `visual/sourceRegistry`、parser worker；保留现有 `htmlDiagnostics.ts` 与 Monaco 语言服务分工，避免使用扫描诊断代替完整位置解析。

## 实施任务

1. 明确 parse5 精确版本、lockfile、浏览器 worker 构建与源码位置选项；选择 P0 通过的版本，不在本文编造已有依赖。节点记录 projectId/epoch/fileId、parseVersion、canvasGeneration、临时 nodeId、类型、UTF-16 区间、源片段/属性、父子/邻居语义上下文及 Yjs 相对锚点。
2. 建立独立于 React 的解析/可编辑分类：有确切来源且边界可证明的节点可编辑；自动补出的 html/head/body/tbody、容错重排、重复属性、无源节点及不明确闭合范围禁止对应写操作，并给出原因/源码入口。不要把所有可容错解析的 HTML 判成可安全修改，也不因局部错误阻断代码输入。
3. 文本区分纯文本、实体和嵌套标签中的具体文本子节点；属性记录引号、原值及可写区间。移动/删除源范围不包含未确定归属的相邻注释；隐式节点只作为投影展示上下文，不能作为可写目标。
4. worker job 绑定项目/epoch/fileId/源码版本/画布代次；仅保留在运行及最新待处理任务。结果返回时匹配当前身份和版本，丢弃迟到任务；超时/预算超限释放任务并显示降级原因。重命名依靠稳定 fileId，但相对资源基准重新生成。
5. 监听本地 Monaco、视觉命令及远端 Y.Text 变化，防抖重新解析；源码变更后选择重新唯一定位或清除，不让旧 nodeId 继续写入。向 Monaco 暴露 fileId+范围的定位接口，首次 UI 接入在 06 完成。
6. 最新命令定位 API 使用相对位置加最新解析/原值/上下文验证。前方无关文本变化只有唯一定位时允许；删除/替换/分裂/父结构变化拒绝，属性原值变化提示冲突。旧偏移不能降级为强制写入；命令层在 03 再检验。
7. 实施 P0 冻结的 200 KiB HTML 与 worker/节点预算；大小用 UTF-8 字节，位置用 UTF-16 code unit。超过 200 KiB 停用设计编辑，保留代码、运行和导出；小于阈值但其他预算超限的说明遵循 P0 决策，不静默减少承诺范围。

## 检查与交付物

交付 parser/registry、worker 生命周期、可编辑分类、定位查询接口和 fixture。明确仅本地缓存，不增加 `designTree/nodeMap`、文件元数据或 Y.Text attributes。节点投影标记由 05 独立生成，不能回写到源码。

| 检查 | 必须断言 |
| --- | --- |
| emoji/中文/实体/CRLF/相同兄弟 | 正确 UTF-16 区间，原始文本不变，节点唯一匹配 |
| 自动 tbody/省略结束/重复属性/错位闭合 | 歧义范围不可写，解释清楚，修复后恢复 |
| 混合文本/未知属性/相邻注释 | 明确可写子区间，不含其他子树或注释 |
| 远端前插/删目标/改属性/父结构变化 | 最新上下文核验，安全定位或拒绝，无旧偏移写入 |
| 切换项目/epoch/文件/重载/销毁 | 迟到 worker 结果丢弃、选择清理、监听和任务释放 |
| 200 KiB 内与超范围 | 边界按 UTF-8 计量，超限代码编辑与运行继续可用 |

覆盖 FR-04/05/10/11/15、NFR-02/03/05 和 AC-04/05/07/14/15/23。单元结果不等于真实画布定位通过，05/06 必须补测。

## 退出与后续

对应 fixture 的区间和可编辑判定通过；构建 worker 成功，迟到结果和歧义节点不可进入写路径；所有失败都保持源码原样。更新 P0 原型到正式实现的差异及实测预算。将稳定的定位/版本/拒绝原因接口交给[03](03-atomic-patch-and-dependencies.md)，把可信节点与资源基准交给 05。应用验证仍使用根 `.env` 和本机服务，禁止 Docker 与凭据输出。
