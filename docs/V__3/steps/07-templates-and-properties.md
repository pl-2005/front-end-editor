# 步骤 07：完整模板、文本属性与实例样式

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P2。前置：[06](06-workspace-and-button-loop.md) 按钮闭环与正式基础门禁。

## 目标与接入

补齐标题、段落、按钮、链接、图片、容器、卡片七类 Bootstrap 原生 HTML 模板，以及文本/属性/样式面板。扩展 templates、属性意图和 03 的计划生成器，所有写入经 04；不引入 React/Vue 源码转换、素材上传或 Bootstrap JS 插件。

## 实施任务

1. 模板注册表记录固定模板/Bootstrap 版本、静态 HTML、可编辑字段、父子约束、必要实例 CSS 和资源需求；容器 row/col、卡片子结构明确合法关系。每次插入独立实例 class，复合组件所有内部标识无冲突。模板缩略图仅在隔离预览加载 CSS，宿主不全局导入。
2. 面板显示当前目标 fileId/nodeId/版本和字段来源。纯文本修改只改指定文本节点；混合内容选择具体子文本或说明限制，绝不以 textContent 清空嵌套标签。文本与属性分上下文编码，保留未改片段、实体和引号。标题级别等涉及标签名的字段以起止标签完整、安全局部计划处理，歧义闭合拒绝。
3. 实现 href、src/alt、button type 及属性新增/删除；未知属性保留。地址输入依据字段允许策略校验，危险内容在设计投影不执行或导航；不把投影清理结果回写源文件。图片仅 URL/既有地址，资源不可用显示原因，不擅自新增二进制文件协议或 MinIO 公共权限。
4. 样式支持宽高、内外边距、颜色、背景、字号、边框和基础 Flex/Grid；值的单位/范围逐字段限定。展示计算值、实际可写声明及来源，默认只改当前实例受控 CSS；手写元素的简单声明改 inline 并标注位置，复杂共享级联只展示计算结果和源码入口。
5. Bootstrap 按钮变体/尺寸等只替换目标受控 class token，保留未知 class。utilities 的 !important、响应式 class、order/reverse/复杂 Grid 不假设可用普通实例声明覆盖；面板展示限制。受支持 utility 字段修改对应 token，不误改 `.btn/.card` 共享规则或静默删除用户 class。布局表示 DOM 顺序与容器，不承诺任意坐标。
6. 连续输入在本地草稿中校验/防抖，提交经最新原值比较和完整计划；离散属性提交一组，连续字段按 04 capture 边界分组，不每帧改 Y.Doc。Esc 取消未提交草稿，焦点/目标/文件/模式变化明确提交或取消规则；旧目标、远端同属性更新、撤权时拒绝旧草稿并提示。
7. 多 HTML 各自按路径解析/引入资源，不改变 entryFileId；已有 Bootstrap/CSS 通过归属验证复用，资源被改名/内容不再可信则提示并保守选新路径。首次 Reboot 影响提示、实际级联顺序、缺安全 head 拒绝和所有容量/许可要求沿 03/06。
8. 所有七类模板支持按钮/键盘插入、面板字段键盘访问、错误文本和状态播报，复用拖拽命令。删除后不自动清理 CSS/vendor，具体结构操作由 08 实现。

## 检查与交付物

交付七类模板注册表与字段规则、文本/属性/样式面板、实例 CSS 编辑及 utility token 映射，补齐多页面可操作流程。

| 场景 | 必须断言 |
| --- | --- |
| 七类逐一插入及重复/复合模板 | 独立实例、父子合法、必要依赖完整，Monaco/画布/第二客户端一致 |
| 混合文本、`<>&"'`、实体/emoji/CRLF | 上下文编码正确，未改子树/未知属性/区间保留 |
| href/src/alt/type 新增/删除及危险输入 | 仅目标变化，设计安全限制有效，原有用户代码不被投影覆盖 |
| 共享 class、Bootstrap utility/响应式、手写 inline | 只改目标，展示真实级联与写入位置，不误改共享规则 |
| 高频输入、取消、远端原值变化、目标/模式切换 | 分组明确，草稿无误写，旧字段拒绝，不产生空历史 |
| 多 HTML、同名资源、重开复用、目录相对引用 | 不重复 link、不覆盖用户文件、不改变运行入口 |
| 依赖/容量/缓存不足 | 所有 HTML/CSS/vendor/许可完整拒绝，无半个组件 |
