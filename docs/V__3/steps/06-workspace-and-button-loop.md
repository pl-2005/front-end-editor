# 步骤 06：工作区接入与按钮最小闭环

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P1。前置：[05](05-design-canvas-and-bridge.md) 画布接口及 02～04 正式基础检查通过。

## 目标与接入

在 `ProjectWorkspace.tsx` / `WorkspacePanels.tsx` 接入组件栏、设计画布、属性栏壳与模式切换；完成正式 Bootstrap 按钮插入到源码、第二客户端及 durable 重开的闭环。此步只完成 P1，不标记七类模板或完整 V3 交付。

## 实施任务

1. 保留文件树、Monaco、在线成员、现有本地/同步/持久化状态与运行控制台。设计 fileId 与代码 activeId、meta.entryFileId 分别管理：初次可选入口 HTML，切换设计文件或点击定位只改变相关本地选择，不调用 setEntry。非 HTML 文件可继续代码编辑；项目无合法 HTML 时给说明及已有文件操作入口。
2. 模式切换使用独立设计 iframe 和既有 Sandpack 运行投影。运行模式执行完整项目，不带设计工具；切回设计重新建立 generation 和映射，旧拖拽/面板草稿/消息失效。侧栏支持收起，按钮与状态有可访问名称，错误不能只靠颜色表达。
3. 组件栏先提供正式 Bootstrap 按钮模板及版本信息、允许父节点/字段；首次引入当前 HTML 时展示 Reboot 全页影响提示和可预览入口。未引用的其他 HTML 不自动加依赖；取消操作不创建文件或 link。
4. 拖动空 body、容器内部和兄弟前后，展示合法目标和插入线。hover/选中框及父层选择使用 05 几何；非法目标明确拒绝，不静默换容器。drop 后经最新定位、03 PatchPlan、04 持久准备/历史门禁提交一次；等待准备期间展示状态，重复点击/drop 不能重复写入。
5. Esc/画布外放下/pointercancel/失焦/重载/文件或模式切换/撤权均调用统一取消；准备中的操作标为中止且不生成源码或空历史。只在成功后选中新实例并重新解析，持续拖动不修改 Y.Text。
6. 点击节点打开其稳定 fileId 对应 Monaco model 并高亮确切范围，反向代码修改刷新设计，选择在最新解析中重建或清除。当前暂停/语法歧义/冲突/资源失败的原因及源码入口可见。
7. 提供按钮式/键盘式“插入到当前容器/当前元素前后”、父层选择和共享撤销/重做入口，复用同命令与校验；不以拖拽作为唯一方式。07/08 扩充字段和结构操作，10 做完整焦点/读屏验收。

## 检查与交付物

交付工作区模式/设计目标状态、组件栏与属性栏壳、按钮模板/拖拽及键盘接入、选择定位与历史工具栏，确保每一项真正进入项目文件。

- 单会话：拖动期间零 Update；合法 drop 一次 HTML/CSS/vendor/许可/link 提交，一次 undo/redo；未触及区间逐字不变。
- 真实两会话：甲插入，乙源码与画布一致；乙改前方文字后甲旧命令安全重验或拒绝。不是仅检查客户端 Yjs hash。
- 等待当前源码“已持久化”后关闭工作区，重新进入检查内容和 Bootstrap；必须通过受控新会话或既有网关重启流程排除本地缓存掩盖服务端持久化，确认权威当前指针的 HTML/CSS/Bootstrap 内容，保留发起者本机恢复材料。
- 多 HTML/重命名/模式切换：运行入口不变，各自相对资源正确；引用失效明确；旧消息/旧面板不能写新文件。
- 提交前 Esc/外部 drop/超限/恢复 prepared 存储失败/无安全 head/撤权：零正文/文件/历史变化，解释一致，恢复准备失败不能先插 HTML。
- 提交后异步本地日志/服务持久化失败：按会话规则暂停后续写入，保留已提交源码、Update 和恢复材料，不自动回滚；沿 04/09 的恢复协议处理并显示尚未持久化状态。
- Chrome/Edge 滚动/缩放/空容器真实投放和替代插入行为等价；宿主 Ant Design 不受 Bootstrap 影响，首次级联影响说明可见。

覆盖 FR-01/03/04/09～13/16～18、NFR-01/02/06～08，执行 AC-01 的按钮子集及 AC-02/03/04/10/11/14/17/20/21/24/25 的对应闭环。AC-01 七类完整验证在 07/11，不能在本步标记整体通过。
