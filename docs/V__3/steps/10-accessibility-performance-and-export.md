# 步骤 10：可访问性、性能清理与运行导出回归

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P4。前置：[09](09-collaboration-offline-and-guards.md) 全操作矩阵及 01 冻结的性能配置。

## 目标与接入

完成桌面 Chrome/Edge 键盘与窄窗口体验、实际规模性能和资源清理，并核对 Sandpack 运行、两种导出入口及项目复制。接入现有 `exportTeamProject.ts`、`projectArchive.ts`、运行投影与工作区，保持权威文件与派生投影分离。

## 实施任务

1. 七类组件、选择父层、前后/内部插入、上下/移入/移出、删除/复制、属性、撤销/重做和 Esc 均有键盘/按钮替代；真实 Chrome/Edge 验证。明确组件栏→画布/选择工具→属性→代码的焦点顺序、iframe 焦点进出和取消后返回位置；侧栏收起/窄窗口不丢当前焦点与可访问名称。
2. hover/选中/禁止投放/冲突/只读及同步状态有文本和可感知提示，不只靠颜色或视觉框。属性标签/错误与控件关联，状态变化可读屏感知，快捷键不抢占文字输入、浏览器或 Monaco 必需行为。替代操作经过同一门禁，不因无 pointer 就绕过恢复准备。
3. 按 P0 设备/规模配置实测从合法操作提交完成到目标 generation ready、布局/选框可操作；记录浏览器版本、文件 UTF-8 字节、节点数、CSS/import/图片成本、次数、p95 和最大值。200 KiB 内要求 1 秒，包含调度/防抖/worker/投影/布局；不能只测发出更新。首次外部加载单列，Bootstrap 本地 CSS成本不得忽略或随意排除。
4. 200 KiB 边界及密集节点/复杂 CSS/资源预算测试，超范围设计编辑明确停用、代码/运行/导出继续；首次加载与复用均测。无范围决策不得提高阈值或删掉预算失败；若小范围页面也超指标，先优化或形成实测影响并同步需求/验收决策。
5. 反复切换模式/HTML/项目、重命名、销毁/重建会话，检查 worker、监听/观察器、MessageChannel/capability、拖拽覆盖层、timer、对象 URL、历史/doc 引用和解析/资源缓存释放。未解决本机侧车继续保留，只有确定撤权/epoch 等沿既有规则清理；资源销毁不能误删恢复材料。无重复命令或持续内存/资源增长。
6. 运行模式回归现有完整 HTML/CSS/JS、入口、控制台和重启，Bootstrap 从项目真实文件加载，设计工具/CSP 改写不进入运行源码。用户动态节点在运行有效，但不能作为设计可写源码节点。Bootstrap JS 交互未新增，用户原有 JS 保持原样。
7. 工作区导出从最新权威 Y.Doc 得到用户源码；项目列表导出按现有权威持久状态读取，明确未 durable 时不能保证列表已有本地未同步内容，必要时提示等待。对同一 durable 状态比较两入口 ZIP 的文件/路径/正文及 Bootstrap CSS/许可；不将本机 conflict 侧车混入公共项目文件。既有显式恢复导出行为如需保留，材料与权威项目文件明确区分。
8. 项目复制沿现有 API 从当前权威文档生成新项目，先确认 durable；检查 HTML/CSS、相对 link、vendor/许可、稳定内容与新项目身份。导出/复制禁止含编辑器临时节点标记、通信 capability/令牌、工具脚本、运行注入文件；用户本来具有同名属性/代码不能凭字符串名称一律删除，按来源断言。
9. ZIP 在受控本机静态环境打开，验证相对 CSS/Bootstrap、图片已有地址与基本用户运行行为；不得依赖宿主私有 URL/CDN 才有 Bootstrap 样式。外部资源自身离线不可用按冻结策略说明，不假称所有外部图片可离线。
