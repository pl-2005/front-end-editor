# 步骤 09：全操作协作、离线重连与统一门禁

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P4。前置：[08](08-structure-commands.md) 正式命令及全部上游核心门禁。

## 目标与接入

将 03/04 已有能力扩展到完整产品矩阵，验证所有视觉操作与 Monaco 共用协作、离线日志、授权和自动持久化。保留现有有界离线编辑，不能改成“只有 online 才可写”。本步不是首次决定结构恢复方案。

## 实施任务

1. 梳理全部写入口：拖拽、按钮/键盘、面板字段、恢复、undo/redo、桥接意图和既有 Monaco/fileCommands；统一读取当前 `state.writable`、身份/epoch、文件存在性及预算。视觉 UI 禁用之外命令层也拦截；不可由 iframe ready、单次 REST 成功或旧闭包 writable 代替当前会话校验。
2. 已初始化且资源可用的设计画布离线插入、属性/结构编辑、undo/redo进入现有 Yjs Update 和 OfflineLog；Bootstrap 固定资源可由安装产物取得，项目依赖仍经同一原子计划/预算。未初始化或资源不可用时说明原因，不假装可以离线加载；设计与运行各自资源状态分开显示，已缓存且可用的运行内容可正常验证。
3. 重连前重新获取票据并复核成员授权/epoch，按既有规则合并已提交 Update，重建映射与资源；不保存/重放旧拖拽和面板意图。旧 parseVersion/generation/requestId 失效；已持久的未解决侧车读取后继续恢复，不能随 accepted/durable 确认删除。
4. 真实两会话覆盖不同节点、同点插入、同属性旧值、源码输入与模板插入、并发首次实例 CSS/Bootstrap、移动/删除及迟到文字；检查最终 HTML 结构/样式、各 fileId/href、冲突说明及恢复文本。纯内存受控队列验证两种到达顺序，真实网关另测归一化和持久化，不靠截图或 CRDT hash 判定成功。
5. 确定撤权、成员退出、项目删除、账号/epoch 变化停止旧写入并清理对应缓存/收据/历史/画布；保留其他成员/项目工作。授权租约复核失败或持久化失败按现有规则暂停，网络/刷新临时错误不清材料。恢复/IndexedDB 准备等待期间变化重验，旧请求不能写新会话。
6. 联合测试暂停、日志满、收据总账满、IndexedDB/Quota 失败及 100 文件（含删除记录）、1 MiB/文件、10 MiB 正文、12 MiB Y.Doc、2 MiB Update、1.5 MiB pending 和缓存总预算。HTML 小不代表 CSS/vendor/许可/历史保留免费；所有入口原子拒绝。预算恢复后的 UI 状态按当前会话更新，不用设计层私自解除阻塞。
7. 状态展示保持本地日志、已同步、已持久化及冲突未解决的区别；durable 指当前权威内容状态，不能让用户误以为冲突材料已解决。暂停理由可定位源码/查看恢复文本；不添加手动快照/版本历史，不绕开网关直接写 MySQL/MinIO。

## 检查与交付物

交付全入口检查台账、正式离线/重连流程、统一禁写原因与状态提示，以及真实服务证据。若未改后端/网关，明确复用已有实现；修改了协议则重审兼容并运行受影响模块检查，不隐式加入 schema 变化。

| 场景 | 必须断言 |
| --- | --- |
| 已初始化离线操作→刷新→重连 | 源码和未解决材料保留，经重新授权合并，Bootstrap 引用正确，无旧意图重放 |
| 不同节点/同属性/同点/结构/迟到更新 | 唯一定位或拒绝、合法但错误合并可检测、内容可查找、相关范围暂停 |
| CSS/vendor 并发首次引入 | 归一化后的真实路径与各自引用一致，重开复用无误 |
| 乙修改/引用甲新增文件后甲 undo/redo | 整组拒绝、正文/身份/历史栈保留；尚未收到贡献进入恢复机制 |
| 撤权/epoch/项目删除与等待中的命令 | 全入口及时停止，旧会话/材料清理正确，无跨项目误写 |
| 提交前超限/缓存准备失败 | 完整拒绝，正文/文件/历史零变化，状态符合真实原因 |
| 提交后异步持久化/本地日志失败 | 按会话规则暂停后续写入，保留已提交源码、Update 和恢复材料，不自动回滚；执行既有恢复协议并说明尚未持久化 |
| 真实 durable 后受控新会话/网关重载 | 权威 HTML/CSS/vendor/许可完整恢复，未解决收据不因 durable 清除 |

覆盖 FR-09/13/14/15/16/18、NFR-03/04/08、AC-10～14/18/20/21/25，同时补测全部 06～08 命令。恢复材料在发起者本机验证，不新增团队跨设备恢复承诺。
