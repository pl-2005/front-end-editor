# 步骤 08：排序、跨容器移动、删除与复制

日期：2026-10-12。状态：待实施；文档审查见[审查记录](../development-review.md)。阶段：P3。前置：[07](07-templates-and-properties.md) 模板规则，以及 01/04 已通过的结构并发检测和本机恢复机制。

## 目标与接入

完成同一设计 HTML 内的兄弟排序、跨容器移动、删除选中源码子树和复制现有元素；跨 HTML 搬迁不作为新增承诺。命令仅扩展 03 计划生成，统一使用 02 映射、04 历史/恢复、05 命中与 06 UI，不直接移动画布 DOM 后序列化。

## 实施任务

1. 定义 move/delete/duplicate 意图：操作源、目标父/邻居、前后/内部位置及 expected 片段/关系。每次命令重新解析并唯一定位源/目标，验证当前身份、epoch、可写状态、代次、容量；过期源被改/删/替换或位置歧义时拒绝并刷新，不用旧偏移强行完成。
2. 统一父子合法性规则：禁止自身/后代、void、head/script、无源/容错歧义节点及非法表格/列表组合；Bootstrap card/row/col 与普通元素规则一致可说明。不静默改投其他容器；CSS order/reverse/复杂 Grid 与 DOM 顺序差异可见。
3. 移动从同一最新快照计算源完整子树、原父和目标插入点；一次计划含删除与插入，补丁无重叠、倒序应用。覆盖同容器前/后移、首/尾/空容器、跨容器和相邻位置 no-op；源插入到自身区间拒绝。保留未知标签/属性/子树；缩进只调整新插片段的必要范围，不重格式化整个文件。
4. 可证明的元素源码区间内所有内部注释随完整子树移动/复制，删除子树时一并删除，模板和手写元素规则相同；区间外相邻注释作为独立节点保留，不凭视觉邻近扩大操作范围，边界歧义拒绝。删除仅选中元素区间，保留相邻兄弟、外部注释及外部 CSS/vendor/许可；同组件重复引用的样式不自动回收。删除后的选择转为可证明的父/邻居或清空。
5. 复制创建独立实例 class 与受控声明，处理整个复制子树中重复 id；先建立旧→新 ID 映射，重写可证明的子树内 for/ARIA/fragment 等引用。子树外引用、未知脚本或歧义引用不能证明安全时提示限制并拒绝该复制，不静默破坏用户语义。保留 Bootstrap class 和未知属性，受控 CSS 归属不明时不覆盖共享规则。
6. 每个离散命令在 04 先持久准备恢复片段，再完整再校验后一次提交/历史分组。相邻 no-op、取消或非法目标均不创建历史；新 CSS/目录纳入全部预检和依赖保护。拖动中零正文写入，工具栏与键盘上移/下移/移入/移出、删除/复制复用同命令。
7. 合并后检测实际结构语义，覆盖 double-move、move-delete、move-late-text、父子同时移动及撤销期间迟到贡献。合法 HTML 重复或漏搬也必须提示；暂停相关设计范围，展示可恢复操作前片段与后来修改，人工恢复重新校验。不通过就停止放行，不能只接受两端 Y.Text 相同。

## 检查与交付物

交付结构意图/计划生成、合法目标反馈、拖拽及按钮/键盘入口、选择迁移、复制 ID/实例处理。记录注释和无法证明引用安全时的具体产品规则。

- 前移/后移/空容器/跨容器正确；emoji/CRLF/注释/未知属性/嵌套子树局部保真，未改区间逐字不变。
- 禁止目标/自身后代/无源/过期命令/no-op 完整拒绝或不写，理由清楚，历史零新增。
- 复制 id 和内部引用映射正确，实例样式独立；未知引用不被猜测改写，删除保留可能复用的 CSS。
- 结构操作一组 undo/redo，fileOrder/目录和引用合法；有远端依赖整组拒绝且栈保留。
- 受控 Update 队列两种到达顺序，以及真实两会话延迟场景：重复/漏搬可检测、源文本可找回、durable 后刷新不清未解决收据。

覆盖 FR-07/08/09/15/17、NFR-01/02/03/06/07、AC-02/03/05/06/11/12/13/14/17/20/24。并发测试同时涵盖代码输入与视觉操作，不用只锁画布证明安全。

## 退出与后续

完整结构及恢复断言通过，特别是合法却错误的合并无静默遗漏；共享历史、多文件依赖与取消无误写。向[09](09-collaboration-offline-and-guards.md)交付全部正式操作，用于离线/授权/容量矩阵，不能把本步核心语义失败延后验收。应用验证使用根 `.env` 和本机服务，禁止 Docker 与凭据输出。
