# 步骤 4：多文件集成、边界与回归

状态：待实施。对应 R1/R6/R7/R8，重点覆盖 A3/A6/A8–A10。前置：[步骤 3](03-templates-properties-and-insertion.md)功能闭环完成。

## 目标与改动位置

收口所有写入口、资源状态、iframe 生命周期和预算；验证多个 HTML 与现有工作区共存。不能把本步当作补做基本安全/恢复的阶段。

主要涉及 `ProjectWorkspace.tsx`、`WorkspacePanels.tsx`、`MonacoWorkspace.tsx`、`session.ts`、`offline.ts`、新增 visual 模块及 `frontend/src/styles/workspace*.css`、`responsive.css`。导出/复制仅在真实回归发现问题时调整；不预先改后端持久化协议。

## 开发顺序

### 4.1 统一全部写入口

逐项对照下表，在每个入口及底层命令核验。按钮置灰不能替代命令级检查：

| 入口 | 需要额外核验的状态 |
| --- | --- |
| 拖拽、点击、键盘插入 | 已准备资源、目标关系、请求去重、取消状态 |
| 文本/属性/style/Flex/按钮变体 | 草稿代次、字段支持、安全值、目标片段 |
| 删除 | 完整元素范围、保留内容已落盘 |
| Bootstrap 准备 | 独立提示、资源/许可匹配、固定 ID、多文件计划容量 |
| 工具栏与快捷键 undo/redo | 候选影响的全部文件、历史栈版本、需要检查状态、恢复预算 |
| Monaco 输入 | 原会话门禁和容量、临时同文件提交锁；持续检查状态不额外禁止正常源码编辑 |
| 文件树删除/重命名/恢复/入口切换 | 与正在提交设计动作的交叉影响；会使桥接/资源状态失效的变更 |

设计命令共同校验项目/用户/epoch、session.writable、文件存在且未删、HTML 预算、解析代次、当前源码及预期片段、检查状态、协议/离线/恢复预算。历史操作按候选结果校验全部受影响文件，不要求当前画布有选中节点。异步落盘前与提交前分别验证；无效请求不能按旧偏移重试。Monaco 和原文件命令继续使用各自原门禁，不把 200 KiB 设计上限或节点解析限制套到普通代码编辑。

原文件命令仍使用既有 session.mutate。增加必要的交叉锁和失效通知，不把所有文件操作改成通用设计补丁平台。历史影响文件可能跨当前选中页面，拒绝必须不消耗任何历史栈项。

### 4.2 核对多 HTML 和资源状态

1. 通过运行页导航检查 `/index.html` 与嵌套 HTML，分别记录代码区 activeId、项目 entryFileId 和当前桥接 fileId；文件树选择只改变代码区。运行 A/代码 B 时 Bootstrap、插入、属性和删除明确作用 A，导航后旧 A 意图拒绝；相对 link 与资源按实际目标路径验证。
2. 已匹配 CSS/许可可多页复用，重复准备不重复 link。两会话并发唯一目录允许重复资源，但不能使引用失效或覆盖用户同路径内容。
3. 当前 HTML 重命名会影响相对路径，CSS/许可删除、重命名或内容变更会影响准备状态；观察文件结构和依赖内容变化，提示缺资源/重新准备，不自动批量改其他 HTML。
4. 保留 fileId 上的恢复材料；路径变化显示新旧路径，不能按旧路径误关联到后来新建文件。删除文件保留已有恢复提示及 V3 材料，禁用设计写入。
5. 运行投影继续只使用真实项目 CSS/link；设计不能额外暗加未入项目的 Bootstrap。通过源码和资源字节核对设计/运行/复制/ZIP 的同版本一致性。

### 4.3 验证缓存、离线、撤权和 epoch

1. 离线写入依赖已初始化文档、内置资源、已加载恢复记录及原会话可写状态；不能把“网络离线”直接等同只读，也不能未初始化就开放写入。
2. 重连先恢复材料再允许设计写入，并核对后续远端事务。online/synced/durable 保留原含义，不表示人工检查已完成。
3. 按[实施约定](../implementation-contracts.md)测试同库联合预算：恢复落盘中断、浏览器配额失败、材料 5 MiB 上限、U/R/Q 共享上限、原 OFFLINE_LIMIT 和多标签争最后容量。同文件提交资格、崩溃预留核对、显式清理引用及异步撤权不能遗漏；确认不覆盖材料、不绕过日志门禁、不自动淘汰。远端合并副本无法落盘时显示不完整状态，日志失败时应用原 session 门禁。
4. 测试文件数、显式目录数、正文、单 Update、Y.Doc 和离线日志边界，包括 Bootstrap 的 CSS/许可成本和逻辑删除文件仍占预算。用真实序列化字节断言，不只看 UI 数量。
5. 用户退出/切账号、项目撤权、epoch 变化沿用现有授权清理路径，先停止旧写入和桥接再清理本地材料；待完成异步回调须检查已失效，不能重新写回清理过的记录。
6. 网络暂时故障与真实撤权分别处理，不能因重试失败清恢复/离线记录。清缓存/换设备不提供跨设备找回能力，在恢复 UI 说明实际范围。

### 4.4 验证 iframe 生命周期与安全边界

1. 普通设计/运行切换只发送检查开关、清状态并取消未提交草稿/落点/命令，保留 iframe、输入值、滚动和脚本状态及有效通道；文件树切换不重建运行页。真实导航/刷新、源码代次失效、项目切换、撤权和 epoch 变化关闭旧通道，取消旧命令/capture/排队回调。
2. 反复切换只剩一个有效通道；检查开关与回执按 mode revision 拒绝旧状态。拒绝旧窗口、旧 capability/nodeId、超大消息、非法数值及重复提交。新增协议属于待实现项。
3. CSS 资源更新沿用 Sandpack 正常运行更新；使布局/落点失效并重新命中，不为静态清洗另建投影。源码代次未变也不能沿用旧几何。
4. 运行检查保留用户 JS/CSS 与原隔离：验证普通选取点击/按压/提交被拦截，切回运行恢复交互；计时器和脚本继续运行，不把检查当作执行隔离。原有 sandbox/父页导航限制不放宽；HTTP/meta CSP 禁止工具时只降级检查，不规避策略。
5. 验证临时 marker 对无引号属性、初始化前 clone/replace/innerHTML 重建和重复标记的影响；源码关联/动态只读/字段与结构偏离分别断言。正文和 ZIP 不含工具脚本、标记或通信信息，恢复库不存 capability/凭据。
6. 纯 CSS 动画、延迟图片/字体、目标移除后检查框及时更新或清除；停止检查后停止帧采样。DOM 父级导航和源码写入父级分别核验，不能因屏幕命中而跳过实施约定第 0 节。

### 4.5 测量性能与检查布局

1. 普通示例记录 HTML/CSS 字节、节点数量、设备/浏览器、从提交到画布可见更新的耗时；目标 1 秒内。Bootstrap 本身计入 CSS 成本。
2. 200 KiB 以下边界页、大 CSS、多次选择/提交测试主线程响应；超过 200 KiB 拒绝设计编辑，但代码/运行保持原有能力。
3. 先调解析防抖和避免不必要重建；只有实测仍明显阻塞才引入 worker。worker 结果仍验证代次，不能异步覆盖较新正文。
4. 检查宽窗口、窄窗口及页面缩放，组件/属性可通过切换面板访问，文件树、源码、成员与原保存状态可用，按钮不被 iframe 遮挡。
5. 键盘焦点顺序、Esc 取消、父级选择、删除和撤销可用；模式切换后焦点有确定位置。文本输入区的常规快捷键不能被结构命令错误捕获。

## 回归清单

| 原能力 | 本步检查 |
| --- | --- |
| 文件树 | 新建、目录、重命名、删除恢复、入口切换、同路径冲突归一化 |
| Monaco | 模型/语言/诊断、远端光标、代码输入、历史、定位、源码面板收起 |
| Sandpack | 原入口、直接 CSS、用户 JS、控制台、重启、HTML 错误后恢复 |
| 会话 | 成员、权限、授权失效、offline/reconnecting、待同步/已同步/已持久化区分 |
| 本机存储 | 普通重开保留、撤权清理、epoch 隔离、同用户多标签材料合并 |
| 导出/复制 | 现有导出和文件恢复目录行为不回归；新增设计材料不混入普通项目导出 |

先运行受影响测试，交付前完成 frontend test/lint/build。若改动 `collaboration/src/document-rules.ts` 等共享协议文件或协作 Node 实现，另运行 collaboration npm test；本方案通常无需改协议。后端若没有修改，真实服务集成在步骤 5 验证，不以 H2 单测代替 MySQL/MinIO。

## 完成条件

全入口使用同一保护逻辑，多 HTML/资源变更不误写，离线与撤权边界通过，旧通信失效，原工作区无新增回归。性能有实测记录，窄窗口与键盘可操作。下一步：[步骤 5](05-local-acceptance-and-delivery.md)。
