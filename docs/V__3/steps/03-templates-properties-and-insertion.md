## 开发顺序

### 3.1 补齐七类静态模板

| 类型 | 源码形态 | 首版编辑能力 |
| --- | --- | --- |
| 标题 | h1 | 纯文本、基础样式 |
| 段落 | p | 纯文本、基础样式 |
| 按钮 | button，btn/btn-primary | 纯文本、type、识别的按钮变体、基础样式 |
| 链接 | a | 纯文本、href、基础样式 |
| 图片 | img，img-fluid | src/alt、宽高及基础样式；无结束标签 |
| 容器 | div | 基础样式、简单 Flex、内部插入 |
| 卡片 | card/card-body 等静态子树 | 容器及各子元素分别选择编辑；不整体替换子树文本 |

1. 模板生成器只返回静态 HTML；不生成随机实例 class、专用 visual-components.css、脚本、事件或工具标记。
2. 模板用户字段按上下文编码。图片地址由用户填写安全 URL/已有地址，不引入上传、远端素材搜索或自动下载服务。
3. 组件栏显示当前 HTML 的 Bootstrap 准备状态；未准备或资源失效时引导独立准备，不能在插入事务里隐式安装资源。
4. 模板样例与实际插入源码共用定义；缩略图样式隔离，不能污染 Ant Design 宿主页面。

### 3.2 实现文本和属性局部修改

1. 属性草稿是本地 UI 状态，输入过程不逐字提交 Y.Text；确认或一次失焦提交一个命令。Esc 取消草稿，不创建历史。
2. 只允许纯文本元素改内容；含子元素/混合文本时显示“到源码编辑”，不抹掉子标签。卡片标题、段落、按钮分别选择。
3. 解码用于展示，写入时按文本或属性上下文编码 `&`、尖括号和引号。处理空值、无引号/单引号属性、新增属性、void 元素，不用正则猜整页标签。
4. href/src 的安全 URL 规则在面板和命令层同时校验；禁止危险协议。button type 限 button/submit/reset，设计画布仍禁止表单提交。
5. 只替换目标属性或文本范围；未知属性、class、相邻空白和未修改源码逐字保留。重复同名属性无法消歧时拒绝该字段。
6. 用户编辑草稿期间源码或选择变更，标记草稿过期并取消提交，提示重新选择；不能把新目标自动套上旧草稿。

### 3.3 实现基础 style 与简单 Flex

| 面板组 | 本步字段 |
| --- | --- |
| 尺寸 | width、height |
| 间距 | margin/padding 及必要的四边字段 |
| 外观 | color、background-color、font-size、border 的基础字段 |
| 容器布局 | display、flex-direction、gap、align-items、justify-content |

1. 采用 CSS 声明解析编辑指定字段，不从浏览器 computedStyle 反写全部 style；声明原文可保留时只打局部补丁。
2. 明确首版接受的值、单位及枚举，属性名由代码固定；允许正常 CSS 值，但不开放原始任意声明输入，不新增复杂响应式/Grid 面板。
3. 字段删除只删除该字段对应的声明；不误删 shorthand、其他未知声明或注释。重复声明、shorthand 冲突和解析歧义不能可靠处理时拒绝该字段，提示源码编辑。
4. 不覆盖/删除用户 class。按钮变体仅替换已识别的 Bootstrap token，保留自定义类和其他 utility。
5. 提交后可在画布核对实际值；被 utility/用户 `!important` 遮盖时展示未生效原因，不修改共享 CSS、其他实例或用户 class 来强行覆盖。
6. 同一属性表单的提交应为一次历史操作；布局改变会引起矩形变化，重新定位选择框，不沿用旧几何信息。

### 3.4 统一结构插入、删除和父级选择

1. 实现 body/普通容器内部、普通兄弟元素前后这三种关系；内部默认追加到明确结束标签前。body 仅在存在安全明确位置时作为目标。
2. 同时检查节点和父容器关系：例如元素本身位置明确但位于表格/list 特殊父结构，也不能做首版结构插入。head、void 内部、隐式容器、SVG/MathML 和特殊结构拒绝。
3. 用同一个候选落点表示组件、fileId、代次、目标 nodeId 和关系。按钮插入、键盘插入、拖拽释放都生成这个意图并走统一命令。
4. 插入只在明确位置增加模板，不重排既有元素、不重新缩进整页。可增加模板自身必要换行，外部原文保持。
5. 删除严格移除选中元素起止范围；img 等 void 使用完整开始标签范围。保留范围外的注释、兄弟和空白，不以自动“美化”扩展删除区域。
6. 选择父级由注册表中的当前关系决定；父级不可写时可展示只读原因，不将它自动替换成可写祖先。命令仍需重新验证。

### 3.5 接入拖拽与键盘替代

1. 组件栏使用 Pointer Events；父层 capture 管理手势与取消，拖动期间只更新本地 ghost/落点，无正文、资源、恢复或历史写入。
2. 父层将指针换算为 iframe 内 CSS 像素，子层通过 elementFromPoint 返回本代命中；父层推导合法 inside/before/after 并显示实际源码插入顺序。
3. 拖过 iframe、滚动容器、浏览器缩放后均核对坐标；不要把拖拽实现成屏幕绝对定位、元素移动或自由坐标布局。
4. 释放时只提交一次请求；重复回执/请求去重。再次验证目标、关系、会话和代次后，才进入落盘与补丁流程。
5. Esc、pointercancel、窗口失焦、画布外释放、超时、iframe 重载、文件/模式切换及失权均取消，并清理 capture/计时器/ghost。
6. 非拖拽用户可以选择容器后点击插入，并用按钮选择 before/after 关系；键盘可操作组件栏、插入、父级选择、删除和撤销。文本框中 Delete/Backspace 不应误删节点。
7. 弹窗/恢复提示关闭后把焦点还给触发入口；状态变化通过可访问说明传达，不只依赖颜色或拖拽标记。

## 验证用例

- 七模板分别在 body、普通容器内、兄弟前后插入，断言实际 HTML 顺序与第二会话同步；卡片逐子元素选择修改。
- 纯文本、特殊字符、中文/emoji、单/双/无引号属性、CRLF、未知属性、注释和重复 id/class：未改区间逐字一致。
- 混合文本、重复属性、style 歧义、void 内部、特殊父结构：拒绝且无正文/历史变化。
- 仅改一个实例的样式；原声明和其他实例不变，utility/important 遮盖有提示。
- 删除目标后兄弟与外部注释完整；本地插入再删除的内容可从恢复记录找回。
- 拖拽过程、取消、失焦、旧目标和重复请求：正文写入次数为零或合法释放的一次，取消无历史。
- 点击/键盘与拖拽得到相同补丁和门禁行为；窄窗口、滚动/缩放和焦点可用。
- 草稿/拖拽期间第二会话改源码或本地切文件，提交拒绝，不套用旧偏移。

编码/补丁/声明编辑用 Vitest，组件草稿/按钮/可访问入口用 React 测试；iframe 指针、缩放、焦点和双会话仍用真实浏览器。不得只检查截图而不断言源码。
