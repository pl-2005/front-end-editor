## 用户流程

1. 进入已有项目，选择 HTML 文件，切换到设计模式。
2. 需要时点击“为当前页面准备 Bootstrap”；展示会影响已有元素样式的提示，成功后再允许插入组件。
3. 从组件栏拖入标题、段落、按钮、链接、图片、容器或卡片；也可选中容器后点击“插入”。
4. 在设计画布悬停检查元素，显示标签与尺寸；源码区展开时同步高亮对应代码，不抢焦点。点击锁定元素后，在属性栏修改文本、属性和基础样式，或删除元素；源码区收起时可打开并定位。
5. 使用撤销/重做，切换运行模式检查页面，等待“已持久化”后重开或导出。

| R3 选择 | 设计画布悬停显示检查框、标签和尺寸；源码区展开时同步装饰高亮及必要的滚动，不抢焦点、不改变插入点；收起时不自动展开。点击锁定选择，保留选中框、选择父元素及打开源码定位入口。悬停不覆盖锁定目标；移出、Esc 或失焦清除临时检查并保留锁定。无法唯一映射的节点只读；源码或代次变化立即清空旧检查/选择/装饰。无 hover 设备可点击定位；运行模式不启用检查。 |

2026-10-26 评审补充：源码定位与可视化写能力分开。初始化前克隆/替换、JS 改字段或移动结构后，映射 ID 不能单独证明可编辑；按文本/属性/结构操作分别保守禁用，继续提供可确认的源码入口。代码活动文件、运行入口与实际检查文件分别保存，写命令绑定有效运行目标的 fileId。具体规则见[实施约定第 0 节](implementation-contracts.md)。新增边界待实现/验证。

## 首版限制

- 只编辑静态、源码位置明确的普通 HTML。拖拽表示 DOM 插入顺序，不是自由坐标定位。列表、表格、SVG/MathML 等特殊结构不接受首版结构编辑，仍可写代码和运行。
- 普通插入容器限定为 body/div/main/section/article/aside/header/footer/nav；前后插入也要求实际父级属于该集合并通过祖先约束。p/span/a/button 内部不开放插入；候选源码必须通过结构再解析，具体矩阵见[实施约定](implementation-contracts.md)。
- 不做元素移动、兄弟排序、复制、复杂 Grid、响应式布局面板、混合文本局部编辑、外部 CSS 级联反写或素材上传。混合文本保留子标签，提示到源码编辑。
- 样式面板直接修改实例内联声明；支持简单 Flex 的 display/direction/gap/align/justify。不分析复杂选择器。遇到 Bootstrap utility 或用户 `!important` 使修改无效时提示到源码处理，不能改共享 CSS 或静默删除用户 class。
- 检查保持运行页原本的 CSS、外部资源和脚本；离线可用性沿用运行页，不额外承诺外部资源可用。CSP 阻止工具桥时仅禁用检查，运行页继续保留。跨源嵌套 iframe 和 Shadow DOM 内部暂不检查。
- HTML 超过 200 KiB 时禁用设计编辑，保留代码和运行；继承项目的 100 文件、1 MiB/文件、10 MiB 正文、12 MiB Y.Doc、2 MiB Update 及离线预算。
- 不承诺自动语义合并。多人改同文件会增加人工检查；恢复材料限当前用户、设备和浏览器，清缓存或换设备无法找回。

## 失败处理与完成定义

命令提交前验证会话可写、项目/epoch/fileId、当前源码版本、目标片段、插入关系和容量。过期命令直接取消并提示重新选择，不按旧偏移重试。只有全部检查通过才写入。

恢复材料在第一次可视化写入前落到有界 IndexedDB；删除、替换和历史操作还须先保存本次将移除的内容，后续意图不能覆盖未清理材料。保存失败或超限则停止相关设计/历史写入。未解决材料不随“已持久化”清除；撤权/epoch 变化按现有规则清理。人工恢复只能复制材料或经重新验证后做局部编辑，不能一键整页覆盖协作者内容。

恢复格式采用可精确重建的基线、可逆补丁及必要快照，不要求每次保存两份整页。固定使用现有 custom store，与更新日志在同一事务内联合计量和预留；5 MiB 材料上限计入同 user/project/epoch 的 CACHE_LIMIT，细则见实施约定。材料不足时保留已有记录并提供显式清理；远端更新正常接收，若最新合并副本无法落盘，须明确提示该副本未保存且暂停相关设计/历史，不承诺其刷新恢复；原日志满或失败则沿用 session 门禁。

历史保护按候选实际影响文件判断：纯代码且不涉及设计记录时保留原历史保护；涉及设计记录的文件先保存可逆材料。一个栈项跨多文件时全部验证，任一受保护文件失败都拒绝整体操作且不消耗栈。Bootstrap 准备不被捕获，不代表用户后续代码修改/撤销永远无法删除 link，失效时提示重新准备。

完成以 R1–R8 和[十项验收](acceptance.md)为准。
