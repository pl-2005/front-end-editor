# V3 首版需求

日期：2026-10-14。状态：待实施。以基础编辑闭环为交付目标。

## 用户流程

1. 进入已有项目，选择 HTML 文件，切换到设计模式。
2. 需要时点击“为当前页面准备 Bootstrap”；展示会影响已有元素样式的提示，成功后再允许插入组件。
3. 从组件栏拖入标题、段落、按钮、链接、图片、容器或卡片；也可选中容器后点击“插入”。
4. 点击画布元素定位源码，在属性栏修改文本、属性和基础样式，或删除元素。
5. 使用撤销/重做，切换运行模式检查页面，等待“已持久化”后重开或导出。

## 首版必须完成

| 编号 | 行为 |
| --- | --- |
| R1 工作区 | 增加组件栏、设计画布、属性栏、设计/运行切换；保留文件树、Monaco、成员和原有保存状态。可切换多个 HTML，设计文件不改变运行入口。 |
| R2 插入 | 七类 Bootstrap 静态 HTML 模板；支持 body/普通容器内部及普通兄弟元素前后。显示实际落点；取消、非法目标和准备失败均不插入。拖动期间不改正文。 |
| R3 选择 | 选中框、选择父元素、定位当前源码范围。无法唯一映射的节点只读；代码变化后更新映射或清空选择。 |
| R4 属性 | 修改仅含文本的元素内容、链接 href、图片 src/alt、按钮 type；卡片子元素分别选择。修改宽高、间距、颜色、背景、字号、边框及容器的简单 Flex 属性。写目标元素的内联 style，保留其他声明和未知属性。 |
| R5 删除与历史 | 删除选中源码子树；代码与可视化操作共用本地历史，一个属性提交/插入/删除是一次撤销。撤销不包含 Bootstrap 资源准备，不删除资源文件，不撤销已观察到的远端贡献；受影响历史操作遇到并发检查状态时拒绝。 |
| R6 源码与模式 | Y.Text 是唯一内容权威；只改明确源码区间，不从 DOM 反写整页。设计模式不执行用户 JS/事件，不提交表单或导航；运行模式沿用 Sandpack。 |
| R7 协作与恢复 | 使用现有授权、容量、自动持久化及有界离线日志。画布与资源已初始化且会话允许写入时可离线编辑。相关远端变化保守提示“需要检查”，暂停该文件设计写入；本机保留修改前、最近本地修改后和当前合并文本供人工处理，刷新仍可找回。 |
| R8 资源与交付 | Bootstrap 固定 5.3.8，CSS/许可存为项目文件，不依赖 CDN；设计、运行、重开、复制与 ZIP 使用同一资源。按钮/键盘替代拖拽，Esc 取消；工具脚本、临时标记、通信信息不得进入用户源码或导出。 |

## 首版限制

- 只编辑静态、源码位置明确的普通 HTML。拖拽表示 DOM 插入顺序，不是自由坐标定位。列表、表格、SVG/MathML 等特殊结构不接受首版结构编辑，仍可写代码和运行。
- 不做元素移动、兄弟排序、复制、复杂 Grid、响应式布局面板、混合文本局部编辑、外部 CSS 级联反写或素材上传。混合文本保留子标签，提示到源码编辑。
- 样式面板直接修改实例内联声明；支持简单 Flex 的 display/direction/gap/align/justify。不分析复杂选择器。遇到 Bootstrap utility 或用户 `!important` 使修改无效时提示到源码处理，不能改共享 CSS 或静默删除用户 class。
- 设计预览支持项目内直接引用的 CSS；首版不展开 CSS `@import`、不加载外部样式/字体、嵌入页面或执行脚本。显示资源限制提示，原文件和运行模式保持原行为。图片允许安全的 HTTP(S) URL/已有可用地址，离线不保证外部图片可用。
- HTML 超过 200 KiB 时禁用设计编辑，保留代码和运行；继承项目的 100 文件、1 MiB/文件、10 MiB 正文、12 MiB Y.Doc、2 MiB Update 及离线预算。
- 不承诺自动语义合并。多人改同文件会增加人工检查；恢复材料限当前用户、设备和浏览器，清缓存或换设备无法找回。

## 失败处理与完成定义

命令提交前验证会话可写、项目/epoch/fileId、当前源码版本、目标片段、插入关系和容量。过期命令直接取消并提示重新选择，不按旧偏移重试。只有全部检查通过才写入。

恢复材料在第一次可视化写入前落到有界 IndexedDB；删除、替换和历史操作还须先保存本次将移除的内容，后续意图不能覆盖未清理材料。保存失败或超限则停止相关设计/历史写入。未解决材料不随“已持久化”清除；撤权/epoch 变化按现有规则清理。人工恢复只能复制材料或经重新验证后做局部编辑，不能一键整页覆盖协作者内容。

完成以 R1–R8 和[十项验收](acceptance.md)为准。
