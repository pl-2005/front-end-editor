# 当前运行页检查模式

日期：2026-10-26。用户确认：设计模式直接检查当前运行页，切换不刷新、不替换页面，保留样式、脚本和当前状态，只叠加检查框。本决定取代原方案中“独立静态设计 iframe、清洗副本、不执行用户 JS”的工作区接入要求；原静态画布代码和证据仅保留为历史实现。

## 当前行为

- `ProjectWorkspace` 始终渲染同一个 `SandpackBridge`。模式切换只改变 `inspecting`，不改变 provider key、预览文件、运行入口或 iframe。原运行页的 CSS、外部资源、用户脚本、输入值和滚动位置保留。
- `RuntimeProjection` 在预览首次启动时加入检查桥，按原始 HTML 开始标签位置加本代临时映射，不序列化用户正文。工具脚本执行后移除自身，页面加载后将临时标记转存 WeakMap 并移除属性。缓存按 fileId/路径/源码复用，切换模式不重新生成预览文件。原有 UTF-8/Vite 补丁继续保留。
- 工具桥只在设计模式处理检查操作。悬停与点击锁定分离，按动画帧合并并去重；检查点击阻止页面点击/按压/提交处理，切回运行恢复原交互。已经运行的脚本、动画和计时器继续运行，检查模式不会暂停应用执行。
- 设计检查时使用临时 adopted stylesheet，将正文元素和伪元素的鼠标统一为默认箭头；输入框、链接和按钮不再随元素切换输入/点击形态。切回运行及页面退出时移除该样式表，恢复原页面 cursor；不改正文、元素内联样式或 Y.Text。
- `RuntimeInspector` 在父层叠加检查框、标签和操作条，不占用渲染页空间；框裁剪在预览 iframe 边界内，使用 CSS 像素。源码悬停仍使用 Monaco decoration，不抢焦点；点击可定位明确的静态源码。
- 悬浮 tag/尺寸标签单独置于目标外侧，按上、下、右、左顺序寻找窗口内可用位置，与目标保留间距；独立浮层不受 iframe 覆盖框裁剪、不拦截指针。目标完全不可见或窗口没有足够外侧空间时隐藏浮动标签，避免覆盖目标。
- JS 生成或无法唯一识别的节点显示标签、尺寸和只读原因，不通过最近父元素猜测其源码。运行时元素不能作为后续写入目标；原静态节点的源码身份不能等同于运行时 DOM 与源码完全一致。
- 当前检查页由运行页决定。文件树选择只改变代码区，不自动跳转或重建预览；需要检查另一 HTML 时先在运行页导航，再启用检查。
- 切换模式清理本地检查状态，保留连接和页面；源码版本变化立即拒绝旧消息并停用旧桥接，等待 Sandpack 正常更新后建立新连接。只有真正导航/刷新/重启、入口或文件结构变化、项目切换才沿用现有运行生命周期。

## 通信与边界

父层验证 iframe.contentWindow、capability、fileId 和代次后转移 MessageChannel；消息限制类型、字段、标签长度、节点注册及有限矩形。重新加载和撤权关闭端口，移出/Esc/失焦清除临时检查，动态删除的目标清除覆盖框。Sandpack 保留原来的远端隔离、sandbox、禁止顶层导航及 no-referrer 配置。

运行页执行用户代码，因此 capability 只能隔离连接，不能作为可信 DOM 或安全写入证明。桥接不接收凭据、不写 Y.Text、不提供任意文件操作。后续步骤 2/3 必须在父层重新验证源码、静态节点结构、版本及持久化保护；不能直接信任运行时消息，也不能按运行 DOM outerHTML 回写源码。原方案的白名单静态清洗/CSS 限制不再套用到运行页，不能继续声称设计模式不执行脚本。

HTML 200 KiB 限制仅作用于检查映射，超限仍保留普通运行页。用户 CSP 阻止检查桥、页面尚未加载完成或不支持的页面，显示检查不可用提示，不重建页面或放宽隔离。嵌套跨源 iframe 和 Shadow DOM 内部不是本次检查范围；完整浏览器开发者工具能力不在本步承诺中。
