# 步骤 08：离线编辑、Presence 与结构操作

> 前置：步骤 07。状态：已实现并完成自动检查及本机功能验收（2026-10-06）。

## 实现记录

`frontend/src/collaboration/offline.ts` 接入固定版本 y-indexeddb 9.0.12 的更新格式和读取器，并使用可确认事务提交的有界写入器，处理配额、事务中止与读取失败。数据库名严格采用 userId/projectId/epoch 隔离；只保存 Yjs 更新、pendingBytes 和未处理恢复提示的 fileId，不保存身份凭据或独立源码副本。单会话未确认更新预算为 1.5 MiB，数据库更新预算为 13.5 MiB（文档上限 12 MiB 加队列预算）；缓冲队列也有硬上限。写事务合并数据库内所有已有更新后原子替换，避免同账号多标签页相互覆盖。只有缓存状态与当前服务端持久化确认一致时才清零待同步计数并进行 GC 编码压缩，迟到回执不能清掉另一标签页的新更新。升级 y-indexeddb 时需复核读取器使用的字段与数据库格式。

`CollaborationSession` 在新票据授权后恢复缓存，首次 ready/schema/sync/persistence 校验通过后允许编辑；已建立的有效会话断线后继续本地编辑。文本输入、补全、undo/redo 和结构命令在临时文档预检 schema、容量及更新预算后才修改真实 Y.Doc。存储故障暂停、未知 schema、非法更新与授权失效不进入离线可写模式。每次重连重新申请票据，相同 epoch 使用 Yjs 因果更新合并并等待 acceptedHash/durableHash 与当前指纹确认；连接恢复不等于已持久化。旧 epoch 或项目身份不匹配时停止重连、销毁旧内容并清理对应队列。

普通导航销毁传输、Monaco 和观察者但保留已提交本地日志；401/403/404/410、网关撤权和注销清理内容及缓存，缓存删除通知其他持有该数据库的标签页关闭编辑。主动退出团队前根据服务端项目授权识别该团队的缓存项目，成功退出后清理，保留其他团队缓存。导出本地 JSON 包与复制恢复内容均先重新请求项目访问确认；网络不可用、已撤权或 epoch 改变时不导出。

Presence 通过独立 Awareness 生命周期管理，发布 activeFileId 与 Yjs 相对选区；网关覆盖 userId、显示名、颜色及 connectionId。成员列表按 userId+connectionId 区分标签页，Monaco 按活动 fileId 与相对位置显示远端选区/光标及成员悬浮提示。断线/离房清理成员和装饰，Presence 不进入 Y.Doc 或持久缓存。修正网关对合法相对位置 `tname: null` 的拒绝，并增加真实 Provider 相对选区回归覆盖。

光标交互补充（2026-10-06）：按可见用户的稳定 userId 分配不同协作颜色，解决不同账号头像颜色相同的问题，同一用户多个标签页共用颜色。光标、姓名标签、选区高亮和成员列表使用一致颜色；姓名以 Monaco 内容组件常驻光标旁，安全使用纯文本，不再依赖悬浮才能识别协作者。折叠选区仍显示光标与姓名，文件切换、删除、离房和工作区销毁清理标签。前端 75 项测试、lint、TypeScript 与生产构建通过；本机浏览器确认姓名标签可见、颜色一致、折叠光标与文件切换清理，截图为 `.codex-build/step08-cursor-label.png`。

结构操作复用 Step07 原子命令、跨扩展名模型重建和确定性同路径归一化。远端逻辑删除活动或有本地修改的文件时，在模型释放前保留内容，提供“恢复为新文件”“验证访问权后复制”“放弃”三种选择；恢复创建新 fileId，不自动复活远端已删除的文件。未处理恢复只记录 fileId，源码继续来自 Y.Doc 的逻辑删除文件，重新打开仍可处理。恢复操作受相同容量和授权约束。

Sandpack 继续单向读取本地 Y.Doc，断线或尚未同步时明确标记“本地未同步”。界面分别显示本地日志状态、连接同步与服务端持久化状态；离线编辑立即使旧持久化确认失效。首次启动或重建 Sandpack 环境需要运行依赖可用，不提供完全离线的依赖安装能力。凭据仍仅在内存：页面刷新/浏览器重启后需显式重新登录，重新授权后恢复本地日志，不提供完全离线登录。

## 离线状态

y-indexeddb 文档名为 `web-editor:{userId}:{projectId}:{epoch}`，只保存受限大小的 Yjs 本地更新和必要序号，不存 JWT、刷新凭据、票据或 MinIO 凭据。断线期间允许当前有效成员继续在本地编辑，文本与结构 transaction 都进入有界队列；达到容量上限时停止新增编辑并提示导出。

重连前重新申请协作票据，服务端复核当前成员关系、项目状态和 epoch。相同 epoch 时按序合并并等待当前 Y.Doc 指针持久化；旧 epoch 不得合入。401/403、退出团队或被移除时关闭房间，清理对应内存与 IndexedDB 队列；仅在服务端仍确认项目访问权时才允许主动导出本地包。项目删除后也不得将旧缓存写回。

## Presence 与文件结构

Awareness 只传 cursor、selection、activeFileId 与受限显示状态；网关按内省结果绑定 userId，离房清理临时状态，不写 MySQL、MinIO 或 Y.Doc。前端展示远端光标和在线成员；同一用户多标签页按 userId+connectionId 明确区分。

创建、重命名、逻辑删除、入口切换使用步骤 07 的原子 Yjs 结构命令。跨扩展名重命名更新 language 与 Monaco model；同路径冲突给出确定性路径及提示；远端删除与本地输入冲突提供恢复/复制当前内容的选择。所有有效团队成员同权操作，撤权用户不能继续编辑。

Sandpack 离线预览只读取本地 Y.Doc，明确标记“本地未同步”。界面分别显示连接同步和当前状态持久化进度，不出现 checkpoint 或历史版本状态。旧 V1 snapshot/revision/restore 接口对 V2 项目持续关闭。

## 功能验收

确认断网继续编辑、刷新/浏览器重启后的本地更新、重新授权后的重连合并、epoch 冲突隔离、撤权清理、Presence/远端光标、结构冲突提示和 Sandpack 本地预览。持久化成功后网关重启可加载最新项目文件。无需专用三服务集成环境或双浏览器自动化；使用根 `.env` 的本机服务，不使用 Docker。
